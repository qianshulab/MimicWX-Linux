## 文档约定

- `HOST` 表示运行 MimicWX-Linux 的主机地址。
- 示例中的 Token、消息 ID、会话 ID 和文件名均为占位值。
- API 认证方式及 `/status` 的访问规则见 API 参考。
- 默认分支的文档对应当前源码；使用旧版本时，请查看相应提交中的文档。
